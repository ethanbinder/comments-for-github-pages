# comments-for-github-pages

Comments for GitHub Pages, powered by GitHub Discussions — no server, no third-party service, no client-side tokens.

A GitHub Actions workflow syncs Discussion comments into static JSON published with your site, and a tiny dependency-free widget renders them on your pages. Works on github.com and GitHub Enterprise Server.
