comments-for-github-pages

This page is a plain static site on GitHub Pages, and the comment thread below is a GitHub Discussion — synced to static JSON by a GitHub Actions workflow and rendered by a single-file widget. No server, no third-party service, no tokens in the browser.

Post a comment through the "Join the discussion" button and it will appear here automatically after the sync workflow redeploys the site (about a minute). See the second page for the empty state and per-page mapping.
